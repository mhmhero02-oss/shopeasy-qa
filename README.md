# ShopEasy QA Project

## Overview
A QA testing portfolio project covering manual testing, test case design, exploratory testing, API testing, SQL, and bug reporting.

## Testing Areas

- Functional Testing
- Boundary Value Analysis
- Equivalence Partitioning
- Exploratory Testing
- Regression Testing
- API Testing
- Database Testing
- Bug Reporting

## Tools

- Chrome DevTools
- Burp Suite
- Postman
- SQL
- Git
- GitHub

## Project Structure
- `test-cases/` - Test cases and scenarios
- `bug-reports/` - Documented defects
- `exploratory-testing/` - Exploratory testing notes
- `api-tests/` - API testing work
- `sql/` - SQL/database testing exercises

## Future Automation

Automation testing with Playwright will be added as project progresses.
